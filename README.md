# Student Management System

## Overview

A console-based Student Management System developed in Java as a Data Structures project. The application demonstrates the implementation and use of static and dynamic data structures to manage student records.

## Features

- Add and delete student records
- Search for students by roll number
- Update student GPA
- Display students in their original order
- Sort students by roll number or GPA using Bubble Sort
- Maintain a sorted linked list of students
- Manage student registration using a queue
- Implement undo and redo functionality using stacks
- Compare the performance of static arrays and dynamic linked lists

## Data Structures Used

- **Array:** Stores student records in a fixed-capacity array.
- **Sorted Linked List:** Maintains student records sorted by roll number.
- **Stack:** Supports undo and redo operations.
- **Queue:** Manages student registration requests.

## Technologies

- Java
- Object-Oriented Programming
- Data Structures and Algorithms

## How to Run

1. Clone or download this repository.
2. Open the project in a Java IDE or terminal.
3. Compile the `DS_Project.java` file.
4. Run the `DS_Project` class.
5. Follow the menu displayed in the console.

If using the terminal, navigate to the directory containing the Java source file and run:

```bash
javac DS_Project.java
java ds_project.DS_Project
```

Ensure that the source file is located in the appropriate `ds_project` package directory when using the package declaration.
